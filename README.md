# Portfolio — Phalonne Guemkam

Portfolio professionnel full-stack moderne développé avec **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4** et **SSR natif pour le SEO**.

## ✨ Fonctionnalités
- **Catalogue de 7 projets d'ingénierie logicielle** avec détails d'architecture technique et modale d'inspection.
- **Carrousel tactile mobile** fluide (`snap-x`, flèches de navigation, points de pagination et compteur dynamique).
- **Grille responsive desktop** avec filtres par catégorie (*Full-Stack & AI*, *Systems & OOP*, *Web & Utilities*).
- **Optimisation SEO maximale** : Metadata complètes, balises OpenGraph, Twitter Cards, JSON-LD Schema.org (`Person`, `WebSite`, `ProfilePage`), Sitemap XML et Robots.txt dynamiques.
- **Design Glassmorphism premium** : Effets de verre dépoli, gradients ambiants et polices *Plus Jakarta Sans* & *JetBrains Mono*.

## 🛠️ Stack Technique
- **Framework** : Next.js 16 (App Router)
- **Bibliothèque UI** : React 19
- **Style** : Tailwind CSS v4
- **Langage** : TypeScript
- **Bundler** : Webpack

## 🚀 Démarrage Rapide

```bash
# Installation des dépendances
npm install

# Lancement en mode développement
npm run dev

# Construction de la version de production
npm run build

# Démarrage du serveur de production
npm run start
```
